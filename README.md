# AML Graph Detection

Research prototypes for AML transaction monitoring using two graph learning approaches: a temporal compound-pattern model and a heterogeneous message-passing neural network. The AML notebook mines bounded account motifs; the HMPNN notebook adapts the published HMPNN architectures to IBM HI-Small.

> **Scope:** Research and reproducibility code. The experiments use synthetic public data and retrospective proxy labels. Results are not production-ready AML decisions and do not reproduce the private DNB study results.

## Quick start

1. Install Python and create a virtual environment.
2. Install HMPNN dependencies with `python -m pip install -r HMPNN/requirements-hmpnn.txt`.
3. Download the HI-Small transaction and account files as described in [`DATA.md`](DATA.md), and place them in a root-level `Data/` directory. The data directory is intentionally excluded from Git.
4. Start Jupyter from the repository root and open either notebook.

To rerun the HMPNN experiment from the repository root, run `python HMPNN/run_hmpnn_notebook.py`. This takes several minutes on CPU and rewrites generated predictions and graph artifacts locally.

## Experiments

### Compound-pattern AML prototype

[`AML/AML_Compound_Pattern_Detection.ipynb`](AML/AML_Compound_Pattern_Detection.ipynb) builds an account transaction graph, compares an edge-aware MPNN baseline, mines bounded two-hop patterns from the chronological training prefix, screens and freezes pattern families, then evaluates a hierarchical-attention fusion model. It caps the sample and candidate search for local execution. The target is an account alert proxy rather than prospective risk over a future horizon.

### HMPNN on HI-Small

[`HMPNN/HMPNN_IBM_HI_Small.ipynb`](HMPNN/HMPNN_IBM_HI_Small.ipynb) imports the original two-layer HMPNN-sum and HMPNN-ct implementation from [`fredjo89/heterogeneous-mpnn`](https://github.com/fredjo89/heterogeneous-mpnn), pinned to commit `4f56e6a38a7e35fd186393c1849f2711392c908b`. It adapts the model to account and entity nodes, transaction relations and the sampled HI-Small labels. It compares against feature-only logistic regression.

The included run used a seeded uniform sample of 100,000 transactions, a static stratified 60/20/20 account split, one seed and a 300-epoch cap. The test split contains 23,814 accounts and 38 positives. AP was 0.0038 for HMPNN-sum, 0.0115 for HMPNN-ct and 0.0156 for logistic regression; ROC-AUC was 0.6726, 0.7621 and 0.6500. Both HMPNN variants reached the epoch cap and had F1 = 0 at their validation-selected thresholds. See [`HMPNN/hmpnn_results/RESULTS.md`](HMPNN/hmpnn_results/RESULTS.md) for limitations and the complete metrics.

Account-level predictions, account split exports and graph serialization are generated when the notebook runs and remain local; they are not committed. The data and these artifacts can be regenerated by following the notebook.
